TC-097

TC-111

TC-169

TC-173

TC-174

Not Automatable — 4 Test Cases

These test cases cannot be automated with Maestro at all due to OS-level requirements, physical verification, or non-reproducible conditions.

TC-001
Remove previous version of OvuSense App software on test device [Android: hold icon until pop-up menu shows; select 'Uninstall'], or test device does not have OvuSense installed.
Reason: Maestro cannot uninstall/reinstall apps. The app package must already be installed on the device before automation begins. This is a pre-condition handled manually.
TC-020
Log out (Settings > LOG OUT) and then sign in again using that new email address. Check app signs in.
Reason: Requires a genuinely new, unique email address created in TC-009. Each automation run would need a fresh email provider integration, which is outside Maestro's scope.
TC-163
Disable haptic feedback. If your phone is haptic-enabled, check moving the graph in the Data tab doesn't create minute vibrations.
Reason: Verifying physical haptic vibration feedback requires hardware-level sensing. Maestro can toggle the setting but cannot detect whether the device actually vibrates.
TC-183
2729: [Android] Improve Sync Logout : Impossible to force occurrence. Pass if standard regression testing okay.
Reason: This defect involves a race condition during sync logout that is impossible to force/reproduce deterministically. Cannot be reliably triggered in automated tests.
